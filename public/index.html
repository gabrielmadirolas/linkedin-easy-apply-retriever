STEP 1

Add your LinkedIn token

Token needed

Generate an access token with LinkedIn's Developer Portal OAuth Token Tools, then paste it here. This app does not need a redirect URL or PKCE setup.

The token is sent only to this local app and stays in memory until you disconnect or stop the server.

First time? Set up your LinkedIn developer app

LinkedIn restricts its Member Data Portability API to eligible members in the European Economic Area or Switzerland. You need a developer app with this API product before generating a token.

  1. Read LinkedIn's Member Data Portability (Member) setup guide.
  2. Create a LinkedIn developer app using LinkedIn's designated Member Data Portability default company page. Do not create a new company page for this product.
  3. In the app's Products tab, request Member Data Portability API (Member) and accept the terms. Wait until the app is provisioned with the product.
  4. Open Docs and tools → OAuth Token Tools in the Developer Portal and choose Create token. See LinkedIn's token-generator instructions if needed.
  5. Select your provisioned app and the r_dma_portability_self_serve scope, request an access token, then sign in and approve the consent screen.
  6. Copy the generated token and paste it into the field above.

You do not need to configure a redirect URL or PKCE for this token-generator flow. LinkedIn may not return every historical answer or link every saved response to a particular job.
