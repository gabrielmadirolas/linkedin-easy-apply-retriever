First time? Set up your LinkedIn developer app

LinkedIn restricts its Member Data Portability API to eligible members in the European Economic Area or Switzerland. You also need LinkedIn to enable the API product and native PKCE for your developer app before the sign-in button can work.

  1. Read LinkedIn's Member Data Portability (Member) setup guide.
  2. Create a LinkedIn developer app using LinkedIn's designated Member Data Portability default company page. The guide warns not to create a new company page for this product.
  3. In the app's Products tab, request Member Data Portability API (Member) and accept the terms.
  4. Ask your LinkedIn point of contact to enable native PKCE for the app. Add its API Key (Client ID) to .env as LINKEDIN_CLIENT_ID=…, then restart this app.
  5. Click Connect with LinkedIn and approve the r_dma_portability_self_serve permission in LinkedIn.

If LinkedIn has not enabled PKCE: use the Developer Portal OAuth Token Tools. Choose your app and OAuth flow, request r_dma_portability_self_serve, approve the request, then paste the generated token above.

LinkedIn's current native OAuth guide: Authorization Code Flow for Native Apps. The API may not return every historical answer or link every saved response to a particular job.
